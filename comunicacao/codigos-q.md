# Códigos Q

O uso adequado dos Códigos Q garante uma comunicação mais clara e eficiente no rádio. Com eles, as informações são transmitidas de forma rápida, organizada e objetiva, reduzindo o tempo gasto em cada transmissão.

{% hint style="warning" %}
É **obrigatório** que todo policial conheça e saiba usar os Códigos Q. Alunos recém-ingressados têm período de adaptação e estão sujeitos ao teste probatório.
{% endhint %}

## Códigos operacionais complementares

Códigos do manual original que continuam em uso na rotina operacional:

| Código | Significado |
| :-: | --- |
| **QRR** | Apoio / reforço imediato |
| **QTI** | A caminho |
| **QTX** | Saindo de serviço |
| **QTO** | Sanitário |
| **QSY** | Mudar de frequência |
| **PTR** | Patrulhamento |
| **QRP** | Acidente de trânsito (botão F3) |

Para os níveis de ocorrência (Código 0 a 7) veja [Códigos de Patrulha e Sirene](codigos-de-patrulha.md). Para os botões rápidos, veja [Comunicação via F3](f3.md).
