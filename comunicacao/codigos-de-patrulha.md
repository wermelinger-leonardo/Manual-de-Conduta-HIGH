# Códigos de Patrulha e Sirene

## Códigos de ocorrência (0 a 7)

Os códigos numéricos indicam o grau de risco e a complexidade de uma ocorrência. Eles padronizam a comunicação entre as equipes, garantindo respostas mais rápidas, precisas e adequadas a cada situação.

| Código | Significado |
| :-: | --- |
| **Cód. 0** | Em patrulha (retorno à patrulha) |
| **Cód. 1** | Baixa intensidade |
| **Cód. 2** | Média intensidade |
| **Cód. 3** | Grande intensidade (alto risco) |
| **Cód. 4** | Sob controle (área limpa) |
| **Cód. 5** | Fogo aberto (código vermelho) |
| **Cód. 6** | Investigando a área |
| **Cód. 7** | Exclusivo do alto-comando: solicita o QRR de todas as unidades táticas em um QTH |

{% hint style="warning" %}
**Perímetro Vermelho** é obrigatório em QRUs de **Código 3** e **Código 5**, em ações fechadas e em qualquer ação de rua que ofereça risco. Em QRUs liberadas como Código 3 não há limite de VTRs; nas demais, respeite o limite operacional e evite comboios.
{% endhint %}

## Códigos de sirene

O uso correto das sirenes garante segurança no trânsito e efetividade das patrulhas.

| Código | Situação | Giroflex | Sirene | Conduta |
| :-: | --- | :-: | :-: | --- |
| **1** | Sem ocorrências | Desligado | Desligada | Seguir todas as normas de trânsito |
| **2** | Ocorrência moderada | Ligado | Desligada | Permitido avançar sinalizações com cautela |
| **3** | Alto risco / urgência máxima | Ligado | Ligada | Situação crítica |

### Atalhos

| Tecla | Ação |
| :-: | --- |
| `Q` | Ligar/desligar giroflex |
| `ALT` (com giroflex ligado) | Ativar sirene |
| `R` | Alternar entre os 3 tipos de sirene |
