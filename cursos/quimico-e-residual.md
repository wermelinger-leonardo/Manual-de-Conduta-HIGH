# Químico e Residual

Neste curso você aprenderá a identificar e analisar substâncias químicas e resíduos em indivíduos, compreendendo a responsabilidade e a conduta exigidas durante abordagens e QRUs.

## Os kits

{% tabs %}
{% tab title="Químico" %}
* Identifica com precisão a presença de drogas, álcool, resíduos ou outros produtos químicos.
* Garante que as ações do policial sejam fundamentadas em provas concretas.

| Resultado | Conduta |
| --- | --- |
| Negativo | O indivíduo é liberado |
| Positivo | A revista pode ser realizada |
{% endtab %}

{% tab title="Residual" %}
* Detecta resíduos de pólvora ou explosivos.
* Indicado quando o indivíduo disparou arma de fogo ou manuseou explosivos (C4) recentemente.

| Resultado | Conduta |
| --- | --- |
| Positivo | O indivíduo é conduzido ao departamento |
| Negativo | O indivíduo é liberado |
{% endtab %}
{% endtabs %}

{% hint style="warning" %}
**Atualizado:** em abordagens de Código 2, o Residual só deve ser usado mediante **suspeita fundada** ([regra 8](../atualizacoes/atualizacao-pm.md)).
{% endhint %}

## Quando aplicar

A análise deve ser aplicada em QRUs envolvendo:

* roubo a ATMs;
* disparos de arma de fogo;
* venda de drogas;
* situações em que o policial não presenciou o delito.

Somente com a confirmação da análise é possível realizar o procedimento correto durante a abordagem.

## Conclusão

O uso correto das análises químicas e de resíduos é essencial para garantir a segurança, a legalidade e a eficiência das operações.

{% endhint %}
