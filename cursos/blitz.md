# Blitz

A Polícia Rodoviária Federal (PRF) tem como missão fiscalizar e organizar o trânsito nas rodovias, sempre priorizando a segurança de todos os usuários. Este curso orienta os oficiais sobre a condução correta de blitz e os procedimentos nas diversas situações que podem surgir durante a operação.

## Procedimentos iniciais

* São necessários **pelo menos três oficiais** para iniciar a blitz.
* As abordagens geralmente são de rotina, mas o oficial pode adotar postura mais rigorosa quando houver justificativa: uso de coldre ou máscara, antecedentes criminais ou veículo que não pertence ao condutor.
* Priorize o roleplay (RP). A blitz não deve gerar conflitos ou ações de rua.
* A revista pessoal em mulheres só pode ser feita por uma oficial feminina (FOX); caso contrário, utilize o procedimento da **caixinha** (caixa do porta-malas da VTR).
* Mantenha sempre o Kit Químico e o Kit Residual disponíveis.

## Níveis de abordagem

{% tabs %}
{% tab title="Código 1 — Instrutiva" %}
* Aplicada em infrações leves de trânsito.
* Foco no diálogo e na orientação do cidadão.
* Não há revista, apenas verificação de documentos. Os oficiais não descem da VTR.
{% endtab %}

{% tab title="Código 2 — Suspeita" %}
* Aplicada quando há suspeita de atividade ilícita, mas sem flagrante visual.
* Verificação do veículo e do passaporte.
* Em QRU de Código 5 sem flagrante, usar o **Kit Residual** (com suspeita fundada); em possível tráfico de drogas, usar o **Kit Químico**.
{% endtab %}

{% tab title="Código 3 — Flagrante" %}
* Quando há confirmação visual da prática de um crime.
* O abordado deve colocar as mãos na cabeça, ser algemado e revistado.
* Se houver coldre, a abordagem é classificada como Código 3.
* Comunicação clara: *“Vou revistar o senhor.”* / *“Estou pegando seu documento no seu bolso.”*
* Mantenha sempre postura respeitosa, independentemente da infração.
{% endtab %}
{% endtabs %}

## Graus de suspeita

| Grau | Características | Abordagem |
| --- | --- | :-: |
| **Baixo** | Todo civil começa aqui, desde que sem sinais de risco. Coopera, não é agressivo e segue as ordens. | Código 1 |
| **Médio** | Age de forma estranha ou incoerente, sem risco direto (resistência leve, insegurança aparente, questionamentos excessivos). | Código 2 |
| **Alto** | Resistência clara, uso de coldre, insulfilme extremo ou veículo não registrado no motorista. | Código 3 |

## Como abordar corretamente na blitz

{% stepper %}
{% step %}
### Inspeção
Verifique se o veículo apresenta danos aparentes.
{% endstep %}

{% step %}
### Conversa
Pergunte ao condutor sobre a origem e o destino do veículo.
{% endstep %}

{% step %}
### Propriedade
Solicite educadamente que o cidadão desça do veículo para confirmar se está em seu nome.
{% endstep %}

{% step %}
### Revista (se necessário)
Se o abordado estiver usando coldre ou desrespeitar os oficiais, proceda à revista.
{% endstep %}

{% step %}
### Liberação
Se nada ilegal for encontrado e o veículo estiver registrado corretamente, libere o condutor.
{% endstep %}
{% endstepper %}
