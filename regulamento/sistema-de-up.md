# Sistema de Up

{% hint style="info" %}
Este sistema de Up serve para **todas as matrizes**. Basta trocar o nome da patente pela correspondente da respectiva unidade.
{% endhint %}

As metas feitas em uma patente contam para o próximo Up, **exceto os dias na patente**. Os registros devem ser feitos nos canais indicados (`prisões`, `multas`, `apreensão`, `bate-ponto`, `relatório-ptr`).

{% tabs %}
{% tab title="Aluno → Soldado" %}
* 5 dias no cargo
* 5 prisões registradas em `prisões`
* 8 multas registradas em `multas`
* 10 apreensões registradas em `apreensão`
* 8 h de PTR registradas em `bate-ponto`
* Ser mencionado uma vez em relatórios de PTR em `relatório-ptr`

**Cursos:** Modulação + Conduta + Patrulha e Abordagem + Químico e Residual + Penal + Prova de Soldado.

**Opcional para virar tático:** Ações Pequenas + Ações Médias + Ações Grandes.
{% endtab %}
